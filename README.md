# 고구마 안내 사이트

파일을 만들고 실행할 수 있는 GPT 작업창에 아래 두 줄을 그대로 보내세요.

```text
https://github.com/xogus6510/goguma-guide-starter
이 사이트처럼 고구마 안내 사이트를 내 PC에서 알아서 만들어줘.
```

GPT가 이 저장소의 코드를 읽고, 내 PC의 작업 환경에 맞게 사이트를 만든 뒤 열어 볼 주소를 알려줘요. 처음에는 예제 상품으로 시작해요. 상품 탭에서 안내 문구를 복사하고 사진 아래에서 원본을 내려받을 수 있어요.

## 사진과 안내를 바꾸고 싶을 때

같은 채팅에 공유할 사진을 첨부하고 **“이 사진과 문구로 바꿔줘”**라고 보내세요. 사이트 제목, 상품 이름·링크, 안내 문구를 적고 사진을 넣을 상품도 알려주면 돼요. [복사해서 쓰는 자료 양식](GPT-PROMPT.md)

## 다른 사람에게 보여주고 싶을 때

같은 GPT에 **“휴대폰에서도 열 수 있게 공유 링크를 만들어줘”**라고 요청하세요. 내 PC에서 운영하는 동안에는 **PC와 인터넷이 켜져 있고 사이트와 공유 연결이 실행 중**이어야 해요.

GitHub에는 예제 코드와 자료만 있어요. 운영 자료와 초대 링크는 내 PC에 보관하고, 첨부하는 사진과 문구는 받는 사람이 열고 내려받아도 되는 것만 사용하세요. 주문 화면, 연락처, 주소, 계정 정보는 첨부에서 빼 주세요.
