# 고구마 안내 사이트 사용법

1. 사이트 만들기

   내 컴퓨터에서 파일을 만들고 실행할 수 있는 GPT에 아래 두 줄을 보내세요. GPT가 사이트를 만들고 열어 볼 주소를 알려줘요.

   ```text
   https://github.com/xogus6510/goguma-guide-starter
   이 사이트처럼 만들어줘.
   ```

2. 사진과 안내 바꾸기

   같은 채팅에 사진을 첨부하고 상품 이름, 상품 링크, 안내 문구를 보내세요. 어느 상품에 사진을 넣을지도 적어 주면 GPT가 반영해요. 사진과 문구에 주문 내역, 주소, 연락처 같은 개인정보는 빼 주세요.

3. 다른 사람에게 공유하기

   같은 채팅에서 휴대폰으로도 열 수 있는 공유 주소를 만들어 달라고 하세요. GPT가 알려준 공유 주소를 보낼 사람에게 전달하세요.

4. 공유하는 동안 내 컴퓨터 켜 두기

   내 컴퓨터를 서버로 사용해요. 내 컴퓨터가 꺼져 있거나 절전 모드에 들어가면 다른 사람이 접속할 수 없어요. 공유하는 동안 인터넷 연결과 사이트 실행도 유지해야 해요.
